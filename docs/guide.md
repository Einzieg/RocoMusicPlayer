# RocoPlayer 使用指南

## 导入曲谱

在「我的谱库」点击「导入文件」选择 TXT 或 MIDI，或点击「添加简谱」输入曲名和简谱。支持 UTF-8 TXT（最大 4 MiB）及使用 PPQ 计时的标准 MIDI type 0 / 1（最大 16 MiB）。MIDI 原谱保留各音轨的音符和变速后的时值，九键适配会跳过第 10 通道的打击乐。每首曲谱最多包含 100,000 个音符。

在左侧搜索框输入部分曲名或来源即可筛选，按 Ctrl+F 可直接定位搜索框。默认按下载或导入时间从新到旧排列，也可切换为「曲谱名称」。切歌和队列播放遵循当前列表顺序。

文本简谱默认每分钟 120 拍、`1=C3`。数字之间用空格分隔，`//` 后面可以写注释。BPM 和基准八度在「应用设置」中调整。示例见[小星星简谱](samples/twinkle.txt)。

```text
5 5 2' 2' 3' 3' 2':2 |
1' 1' 7 7 6 6 5:2
```

| 写法 | 含义 |
| --- | --- |
| `1` 至 `7` | 一个音级，默认一拍 |
| `2'`、`6,` | 升高或降低一个八度 |
| `#4`、`b7` | 升、降半音 |
| `0`、`-` | 休止、延长前一个音符或和弦 |
| `5:2`、`3:1/2` | 两拍、半拍 |
| `[3 5 7]:2` | 同时奏响三个音，持续两拍 |

## 本地音频和在线乐谱

在「音频转谱」选取 0.1 至 300 秒的 WAV、MP3、FLAC 或 Ogg Vorbis 文件。支持 8 至 192 kHz、1 至 8 声道。转谱完成后会新增一首曲目，之前保存的谱子可继续使用。

| 引擎 | 适用场景 |
| --- | --- |
| 乐器音符模型 · Basic Pitch | 本地 ONNX 推理，可设置偏高、偏中或偏低的主奏音区。实验性「保留和弦」会在识别旋律上增加有证据的伴奏音。 |
| 频谱主旋律 | 从频谱与谐波中寻找旋律，可与模型结果对比。 |
| 独奏单音 · YIN | 清晰的独奏或哼唱，一次识别一个基频。 |

C# 版将新识别结果标记为 `csharp-v1`。合奏、混响和弱起音会影响选音与时值，音区偏好也可能选中不同声部。音频识别在本机完成。模型来源、输入输出与文件校验信息见[模型记录](../src/RocoPlayer/Assets/models/basic-pitch/SOURCES.json)。

「在线下载」支持按曲名或作者搜索、翻页浏览。点击「下载到我的谱库」后，公开 MIDI 保存在数据目录的 `online-scores/` 中，同一个曲谱的相同文件版本只入库一次。遇到网站响应或格式错误，可取消任务后重试。

## 九键编配与试听

本地导入、添加简谱和在线下载均使用 RocoMusic 工作台默认的九键适配流程。多轨 MIDI 优先选择名称含 Melody、Lead、Vocal、旋律或主唱的非打击乐轨，否则使用第一条有音符的非打击乐轨。程序按整条音轨选择移调量和九键音高，保留起音时间，合并同键同刻的音符，并在同键再次触发时截短前音。默认九键音高与 RocoMusic 一致，实测校准后按本机键位适配。原谱和九键结果分别保存。

选择曲目后，右侧可以切换「9 键谱」和「原始音符」。横轴表示时间，纵向各行表示键位或原始音高，条形长度表示时值。下方列出原始音符数、适配后音符数和目标键位数。点击曲名右侧的「导出九键 MIDI」保存适配结果。

「试听」使用随程序附带的 RocoMusic v2 游戏实录。每个键都是一段六秒的立体声手碟敲击，短音符也会留下自然余音，和弦和连击可以重叠。「应用设置」中的速度倍率会改变音符间隔，录音本身的音高和衰减速度保持一致。

底部播放条显示当前曲名和播放进度。在任一主页面都可以点击「试听」，从选定位置听到曲末的余音。试听期间拖动进度条可直接跳转。

- **试听原音频**播放用于转谱的本地音频。移动原文件会影响这一项。
- **原始音符**保留原始音高，九键以外的音使用最近的录音按半音移调。距离相同时选择较低的录音。
- **9 键谱**使用同一套录音播放适配结果，可与原始音符对照。

点击「停止试听」或按 F10 可结束试听。在「应用设置」勾选「无按键预览」，点击底栏的「开始预览」可无声检查时间轴和队列。

## 真实演奏与播放队列

1. 在游戏中打开乐器，在「我的谱库」选中曲目。首次演奏默认使用 DD，可在「应用设置」选择并保存 DD 或 Win32 后端，也可修改九键映射。
2. 点击顶栏左端的「捕获游戏窗口」，在三秒内切到目标游戏。成功后，按钮会显示「已捕获到」及窗口名称。再次点击可以更换目标，倒计时中再次点击可取消此次捕获。
3. 点击底栏「开始演奏」或在游戏中按 **F8**。播放器会准备所选输入后端、激活捕获的窗口，并按九键谱发送按键。使用 DD 时，可复用旧版 RocoPlayer 已安装的 63340 驱动。在「应用设置 → DD 只读诊断」可查看 DLL、服务和设备状态。
4. **F9** 暂停或继续，**F10** 停止队列、释放按键、取消后台任务并停止试听。失焦会暂停，输入错误或窗口关闭会终止队列。若释放按键失败，请按界面提示再次停止。
5. 点击底栏右端的「置顶小窗」图标即可打开小窗，也可勾选「真实演奏时进入置顶小窗」让它随演奏打开。小窗中的圆形按钮控制播放、暂停和继续，两侧图标用于切歌和停止。点击右端的「展开谱库」图标返回主界面。

主窗口底栏和小窗的播放键旁都可以切换模式，选择会自动保存。**顺序播放**在列表末尾停止。**随机播放**从其他曲目中打乱选择。**单曲循环**在曲目自然结束后重播，仍可手动切歌。**列表循环**在末尾回到第一首。播放速度范围为 0.25 至 4 倍。按键保持时长为 10 至 150 毫秒，短音与快速重复音会进一步缩短按键脉冲。

### 键位和实测校准

| 按键 | B | F | G | H | J | K | T | Y | U |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 默认音高 | A2 | E3 | F3 | G3 | A3 | B3 | C4 | D4 | E4 |
| MIDI | 45 | 52 | 53 | 55 | 57 | 59 | 60 | 62 | 64 |

手动设置时，使用九个互不重复的 MIDI 音高和九个独立的字母或数字键。已有 DD 环境也可以实测。先关闭背景音乐与其他系统声音，保留乐器音效。保存 DD 后端、捕获游戏并点击「实测九键音高」。确认后在三秒内切回游戏。校准会真实发送九个测试键并录制默认系统输出，九个测量均成功后才保存新映射。录音与测量结果位于数据目录的 `calibration/`。

DD 通过全局输入发送按键，游戏与驱动的兼容性需要在目标机器实测。设置页的「DD 只读诊断」可以检查文件、服务和设备状态。[DD 安装与诊断](packaging.md#dd-诊断)

## 谱库与备份

默认数据目录为 `%APPDATA%\com.rockmusic.workspace-player\`，可通过 `ROCK_MUSIC_DATA_DIR` 覆盖。版本 1 的 `library.json` 保存原谱、九键谱、来源、设置、当前曲目和播放模式。删除当前曲目后，按屏幕上的排序及搜索结果选择下一首。删除末行时选上一首，结果为空时清空选择。源文件保存在原位置。为保留分段试听，另行备份用户选择的原音频。

关闭播放器后复制整个数据目录即可备份，包括下载的 MIDI 与校准录音。如果读取旧谱库失败，屏幕会提示出错路径，原文件会保留。恢复备份前，先把当前目录另存一份。

## 离线重编

若想改善早期编配中的旋律转折，可对备份执行 C# 离线重编。下例中的 `artifacts/library.before.json` 是已保存的曲库快照，输出目录必须是新路径。在仓库根目录执行下列命令。

```powershell
$ErrorActionPreference = 'Stop'
dotnet run --project tools/RocoPlayer.Contour -c Release -- artifacts/library.before.json artifacts/contour-candidate
if ($LASTEXITCODE -ne 0) { throw '离线重编失败' }
```

工具尝试保留旋律的升降、峰值和同音重复，并按曲目配置重建稀疏低音。已有九键成品、多声部未确认的和弦及不支持的编配模式会保留，并在 `report.json` 中列明原因。输出的候选 `library.json` 保留原谱、曲名、设置和顺序。确认所有播放器均已退出后，可把 `ROCK_MUSIC_DATA_DIR` 设为候选目录，打开播放器试听。

## 独立工具

**从音频导出 MIDI**。在仓库根目录执行下例，将音频路径替换为自己的录音。输出目录中会生成同名的 `.original.mid`、`.9keys.mid` 和 `.report.json`，分别用于核对识别结果、演奏九键谱和查看逐音改动。同一目录中的同名结果会更新。可按 Ctrl+C 取消。

```powershell
$ErrorActionPreference = 'Stop'
dotnet run --project tools/RocoPlayer.Arrange -c Release -- ./录音.wav --engine instrument --register auto --output ./artifacts/arrangements
if ($LASTEXITCODE -ne 0) { throw '音频编配失败' }
```

`--engine` 支持 `instrument`、`melody` 和 `yin`，`--register` 支持 `auto`、`high`、`mid` 和 `low`。用 `--settings <路径>` 可读取已有 `library.json` 或个人 `music_settings.json` 的键位映射。省略该选项时，工具先查找当前目录的 `music_settings.json`，未找到设置文件时使用内置默认映射。

**命令行实测校准**。`tools/RocoPlayer.Calibrate` 与设置页共用实测逻辑。用 `--hwnd` 指定游戏窗口句柄（十进制或 `0x` 十六进制），`--output` 指定测量结果目录。可用 `--focus` 请求切回游戏、`--wait-foreground` 指定等待前台的秒数、`--delay` 设置测试前的延迟秒数。运行测量时会实际发送测试键并录制输出。工具将 WAV 和 JSON 保存到输出目录。可用 F10 或 Ctrl+C 取消。要将实测音高直接保存为播放器映射，请使用设置页的校准功能。

**独立连点器**。从仓库根目录执行 `dotnet run --project tools/RocoPlayer.Clicker -c Release`。在单独的 WPF 窗口中设置触发间隔、动作、目标按键和发送模式。默认按 F8 开始或停止连点，与播放器共用 F8 时请只运行当前需要的工具。
