# RocoPlayer v0.2.3

## 更新

- 点击 DD 播放时，先完成初始化再缩小窗口、请求切回游戏；初始化失败时保留播放器窗口。
- 初始化后的 Win 键保护延长至 520ms，增加并发初始化锁和持久化运行日志。没有新增 Ctrl/Shift 等补救按键。
- 已知版本 DD DLL 在首次加载前进行 SHA256 校验，安装包构建时校验完整 DD 原始组件。
- 设置页新增「DD 驱动诊断」，只读检查文件、服务、PnP 设备及安装超时标记，不初始化 DD、不发送按键、不自动重装。
- 保留 v0.2.2 的 VC++ 运行库补齐、服务/PnP 安装检查和持久化安装日志。

## 安装与日志

保存内容并正常退出旧播放器后，运行 `RocoPlayer_0.2.3_x64-setup.exe`。包含运行环境、模型及 DD 组件，无需启动脚本。附 `SHA256SUMS.txt` 用于下载完整性校验。

- 运行日志：`%LOCALAPPDATA%\RocoPlayer\logs\dd-runtime.jsonl`，保留两份轮转备份。
- 安装日志：`%PROGRAMDATA%\RocoPlayer\logs`。

自定义 DD 版本若没有内置哈希基准，会标注为未验证。诊断读取到服务/设备正常不等于真实游戏输入验证通过。

## 验证范围

Python 232 项回归测试：228 通过、4 跳过；前端 24 项测试、类型检查和前端构建通过。已验证本机只读设备查询和原始 DD 文件哈希。

独立打包引擎已通过启动、只读 DD 诊断和正常退出检查；5 个 DD 原始组件哈希匹配，3 个 VC++ 运行库可读取。Tauri Release 编译通过。

没有进行真实按键或干净 Windows 虚拟机安装验收，不保证解决所有 Win 键弹出或 DD 返回 0 的情况。应用安装包未签名，可能触发 SmartScreen。
