# RocoMusicPlayer v1.0.0

首个 C# / WPF 正式版。原 RocoPlayer 谱库可以直接打开，曲谱、键位和播放模式沿用原有数据。

## 安装

下载 `RocoMusicPlayer-win-x64-Setup.exe`，在 Windows 10 或 11 x64 上运行。安装包自带桌面运行时、音频模型和 DD 63340 驱动。安装前会检查现有服务和设备，已就绪时跳过，缺少时自动安装。有异常记录时会提示查看日志。可以在同一发布页下载 `SHA256SUMS.txt` 校验安装包。

## 本版变化

- 本地谱库支持搜索、两种排序、原谱与九键时间轴对照，以及直接导出九键 MIDI。导入的 MIDI 和简谱会自动适配九键。
- 试听使用游戏实录的九键手碟音色。底部播放栏和置顶小窗都可切换顺序播放、随机播放、单曲循环与列表循环。
- 支持捕获与重新捕获游戏窗口，使用 DD 或 Win32 演奏。首次 DD 初始化会处理延迟到达的 Win 键事件，游戏失焦时自动暂停并释放按键。
- 在线谱库可搜索和下载 MIDI。音频转谱可使用本地 Basic Pitch、频谱主旋律或 YIN。

开始演奏按 **F8**，暂停或继续按 **F9**，停止按 **F10**。[使用指南](https://github.com/Einzieg/RocoMusicPlayer/blob/v1.0.0/docs/guide.md)
